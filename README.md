# Idllyc MMO status

The status page of [Idllyc MMO](https://idllyc.mmorpg.ovh): https://nejimatv.github.io/idllyc-status/

[Upptime](https://upptime.js.org) checks the game every 5 minutes from GitHub
Actions, outside our servers, so the page stays up when the game is down. A
check that fails opens an issue here, closed when the service answers again;
the issues are the incident history the page shows. Configuration:
`.upptimerc.yml`.
